## 2. Creative concept: "Every celebration begins with a circle"

The Bliss logo is a **red circle**. A Punjabi bride's wedding begins with the **chooda**: red-and-ivory bangles, also circles. A family firm that has come back to the start over four generations is a third circle. So the site has **one signature object, the chooda**, and it tells the story:

- **Loader:** a red dot becomes the logo while the years count up from 1935 to 2026.
- **Hero:** a 3D chooda stack (red lacquer, ivory, gold kundan bands) floats over a giant "Bliss" wordmark and tilts toward the cursor.
- **Scroll:** the bangles turn to face you, and the camera passes through the circle into the brand-red story section.
- **Ceremonies:** a bangle rolls along the bottom of the horizontal strip and changes colour with each ceremony.
- **Close:** the page turns entirely Bliss red, so the visitor ends inside the logo.

**Supporting motifs**
- **Cusped arches.** Image masks use the multifoil arch of Amritsar's heritage architecture instead of the generic rounded arch.
- **Ceremony colour system.** Colour carries information, like Knurl's plate colours. Every ceremony has its own colour, used on its panel, its markers and its page transitions.

- **Gurmukhi accents.** Each ceremony carries its Punjabi name (ਮਹਿੰਦੀ, ਜਾਗੋ, ਅਨੰਦ ਕਾਰਜ…), and the hero opens with ਜੀ ਆਇਆਂ ਨੂੰ ("welcome"). A native speaker should proofread these before launch.
- **Real reels.** Their own YouTube Shorts sit inside the site, so the work they're proud of is one tap away.

### What we took from the references
- **Peno Lab "Tyler & Marie":** tilted polaroids with script names in the hero, editorial condensed serif, and a dark footer with a big sign-off.
- **"Our Recent Works" bento:** arch-topped images with overlay titles and circular arrow buttons, used for Signature Celebrations.
- **Wedify:** giant serif wordmark over the subject, script couple names, a rotating circular text badge, and a curved section edge.
- **BV Luxury (Italy):** a deep red luxury palette, testimonial cards and a press/proof strip. It lines up naturally with the Bliss red.
- **Knurl Gym (our own):** one signature 3D object, a story loader, pinned horizontal scroll, cursor-follow image reveals, a morphing selector instead of three equal cards, one deliberate theme switch at the close, all copy in one content file, and reduced-motion support.

**Avoid:** generic gold-on-black luxury, stock "white wedding" Western imagery, emoji, rating chips floating over the hero, three equal pricing cards.

## 3. Design system

The palette comes straight from the logo: a red field with white letters. Tokens live in `src/app/globals.css`.

**Colour**

| Token | Hex | Use |
|---|---|---|
| `bliss` | `#D7262B` (sampled from logo) | Brand, primary buttons, story and closing fields, footer invitation card |
| `bliss-deep` | `#A8161C` | Hover and pressed states |
| `wine` | `#4A0B10` | Films section, footer |
| `ink` | `#2B0E10` | Text (an oxblood drawn from the red) |
| `ground` | `#FFFFFF` | Page base (the logo's white) |
| `blush` | `#FBEBE8` | The one tone step for surfaces |
| `stone` | `#F4EEEB` | Neutral tone step |
| `muted` | `#6E4F4C` | Secondary text |

**Type**
- **Jost** is the single family. Display is set at weight 300, large and tight; it is geometric, like the logo's "EVENTS & DREAM WEDDING PLANNER" lettering.
- **Noto Sans Gurmukhi** sets the Punjabi words (ਜੀ ਆਇਆਂ ਨੂੰ, ਹਲਦੀ, ਮਹਿੰਦੀ…).
- Headlines are two lines at most. No eyebrow labels, and no accent word in a headline.

**House rules (client brief)**
- No em dashes.
- No decorative lines or 1px boxes.
- No pills: buttons are flat with a 2px radius.
- No gradients except photo scrims; no glass or glows.
- The nav has no background. Each part of it (logo, links, button) reads the ground under it and switches between ink and white.

**Shape**
- Cusped Amritsar-arch masks and circles for imagery. Everything else is square.
- The cursor is a normal arrow and hand in Bliss red, white on red or dark grounds, with Play and Drag variants over films.

**Motion**
- One signature move: the chooda pass-through in the hero.
- Supporting moves: section entrances, the ceremonies pin, count-up stats, and the footer card tilting toward the cursor.
- **Reduced motion:** no smooth scroll, no pins, a static bangle and instant reveals.

## 5. Tech architecture

| Layer | Choice |
|---|---|
| Framework | Next.js 16 (App Router, RSC, TypeScript) |
| Styling | Tailwind CSS v4, tokens in `globals.css` (`@theme`) |
| Motion | GSAP 3.15 + ScrollTrigger + SplitText (via `@gsap/react` `useGSAP`), Lenis smooth scroll, Motion (Framer Motion) for the menu, reel player and review swaps |
| 3D | React Three Fiber + three (no drei): chooda scene lazy-loaded, lit by three's RoomEnvironment, paused when out of view, flat SVG fallback without WebGL |
| Images | `next/image` with a custom loader (`src/lib/image-loader.ts`): Unsplash resizes on its CDN; the client's own pictures are pre-sized to WebP by `scripts/resize-images.mjs` |
| Content | Phase 1: `src/content/site.ts` (single file, like Knurl). Phase 2: Sanity CMS for weddings, reels, reviews, journal |
| Fonts | `next/font/google`, self-hosted, subset |
| Forms | Server Action → Resend email + WhatsApp deep link + Google Sheet/CRM webhook; Turnstile spam check |
| Video | `lite-youtube-embed` style facade (load the iframe on click) |
| Analytics | Vercel Analytics + GA4 + Meta Pixel (lead events on WhatsApp/enquiry) |
| Hosting | Vercel |

```
src/
  app/(site)/page.tsx, weddings/, ceremonies/[slug]/, services/, plan/ …
  components/  Nav, Footer, Loader, Cursor, Button, ArchImage, ReelCard, Lightbox, PageTransition
  sections/home/  Hero, Legacy, Signature, Ceremonies, Services, Reels, Process, Reviews, Destinations, PlanBuilder, Faq, Closing
  three/  ChoodaScene.tsx, Bangle.tsx
  lib/  lenis.ts, gsap.ts, whatsapp.ts, seo.ts
  content/site.ts
```

**Budgets:** LCP < 2.5 s on 4G, CLS < 0.05, JS < 200 KB before the 3D chunk, Lighthouse 90+ on all four categories, WCAG 2.2 AA.

## 7. Prototype notes

- Run it with `npm run dev`, then open <http://localhost:3000>. The `.claude/launch.json` config also starts it. `npm run build` produces a fully static home page.
- **Pictures:** `public/reels` holds covers of The Bliss's own YouTube Shorts, and `public/insta` holds images from @thebliss.weddingcompany. Unsplash is only used where they have nothing yet (food, Goa, Jaipur, Jammu, the Golden Temple). After adding pictures, run `node scripts/resize-images.mjs`.
- **Reviews:** the quote box uses two short lines from public Google reviews, verbatim. The video testimonials are their own Shorts.
- **Copy:** all copy lives in `src/content/site.ts`.
- **The plan form:** it has no backend yet. "Send enquiry" validates the name and phone, then opens WhatsApp with the plan filled in. Phase 4 adds the Server Action and email.
